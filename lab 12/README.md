**Крайняк Михайло Юрійович, 451 група**
Варіант 10 — розклад маршрутів автовокзалу. Звіт: [report.pdf](report.pdf).

## Можливості

- `index.php` — список рейсів із пошуком за пунктом призначення;
- `route.php?id=…` — сторінка одного рейсу (аналог `book.php` з прикладу бібліотеки);
- `register.php` — реєстрація (логін, ПІБ, email, пароль); пароль зберігається лише як хеш `password_hash()`;
- `login.php` / `logout.php` — вхід і вихід, користувач зберігається в сесії;
- `users.php` — список користувачів, доступний лише після входу;
- `db_check.php` — перевірка підключення PDO і структури таблиці `users`;
- спільне верхнє меню: для гостя — «Увійти» і «Реєстрація», для користувача — привітання й кнопка «Вийти».

Усі запити з даними користувача — підготовлені (`prepare` + `execute`), `PDO::ATTR_EMULATE_PREPARES = false`,
помилки — винятками `PDOException`; користувач бачить загальне повідомлення, деталі пишуться в журнал сервера.
Форми захищені CSRF-токеном, після успішного POST — перенаправлення 303, після входу — `session_regenerate_id()`.

## Запуск (XAMPP)

1. У XAMPP Control Panel запустіть **Apache** і **MySQL**.
2. Створіть базу: phpMyAdmin → «Імпорт» → `sql/schema.sql`, або з каталогу роботи:
   ```bash
   C:\xampp\php\php.exe sql/setup.php
   ```
3. Скопіюйте папку в окремий каталог `C:\xampp\htdocs\lab-12` (інші проєкти не видаляйте)
   і відкрийте `http://localhost/lab-12/src/`.
   Або запустіть вбудований сервер із каталогу роботи:
   ```bash
   C:\xampp\php\php.exe -S 127.0.0.1:8000 -t src
   ```
   і відкрийте `http://127.0.0.1:8000/`.

Параметри підключення (типово XAMPP: `127.0.0.1:3306`, користувач `root` без пароля, база `lab12_bus`)
змінюються змінними середовища `LAB12_DB_HOST`, `LAB12_DB_PORT`, `LAB12_DB_NAME`, `LAB12_DB_USER`, `LAB12_DB_PASS`
або файлом `src/config.local.php`, який повертає масив із ключами `host`, `port`, `name`, `user`, `pass`
(файл не додається до репозиторію).

Користувачів у базі спочатку немає — зареєструйтеся через `register.php`.

## Перевірки

`bash tools/checks.sh` (Git Bash) при запущених серверах `127.0.0.1:8000` і
`LAB12_DB_PORT=3999 php -S 127.0.0.1:8001 -t src` (сервер із недоступною БД для перевірки обробки помилок).
Скрипт перестворює базу. Результат останнього запуску — [tools/checks-output.txt](tools/checks-output.txt).

Перевірено на PHP 8.2.12 (XAMPP) і MariaDB 10.11.19; код сумісний з PHP 8.1 і MySQL/MariaDB з XAMPP.
Усі дані вигадані.
