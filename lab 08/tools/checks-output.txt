################ Пошкоджені та невідповідні файли
xml  відсутній файл        GET 500: Файл даних відсутній або недоступний для читання. | POST 500, файл не змінено
xml  порожній файл          GET 500: Файл даних порожній. | POST 500, файл не змінено
xml  порожній список routes GET 200: Записів немає | POST 303, файл ЗМІНЕНО
xml  незакритий тег        GET 500: Некоректний синтаксис XML. | POST 500, файл не змінено
xml  DTD із зовнішньою сутністю GET 500: DTD у форматі каталогу не дозволено. | POST 500, файл не змінено
xml  інший корінь            GET 500: Очікується кореневий елемент routes без атрибутів. | POST 500, файл не змінено
xml  відсутнє поле price    GET 500: Запис 1: відсутнє поле price. | POST 500, файл не змінено
xml  повторне поле number   GET 500: Поля route: id, number, destination, departure, platform, price без повторів і атрибутів. | POST 500, файл не змінено
xml  platform=abc                       GET 500: Запис 1: Платформа — ціле число 1–20. | POST 500, файл не змінено
xml  price=0100 (початковий нуль) GET 500: Запис 1: Ціна — ціле число гривень 1–5000. | POST 500, файл не змінено
json відсутній файл        GET 500: Файл даних відсутній або недоступний для читання. | POST 500, файл не змінено

json зайва кома                GET 500: Некоректний синтаксис JSON. | POST 500, файл не змінено
json об’єкт {}                   GET 500: Кореневе значення JSON має бути масивом. | POST 500, файл не змінено
